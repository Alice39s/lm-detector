检测网站 [lm.ikale.io](https://lm.ikale.io) 是纯前端应用：挑战生成、特征提取、排名和核验都在浏览器中完成，参考库以静态文件下发。网页只检测和只读浏览参考库，不向参考库写入任何回复。API Key 只在发送请求时发给你填写的接口，或经你同意的转发代理，见[直连与代理授权](./connection.mdx)。

## 取样方式

<Tabs items={['手动', 'API']}>
  <Tab value="手动">
    页面生成三道挑战。把每道挑战分别发给目标模型（例如在聊天界面中新开会话），再把回答粘贴回对应的样本框。适合只有聊天界面、没有 API Key 的情况。提示词和回复不会被翻译，切换界面语言也不会改变它们。
  </Tab>
  <Tab value="API">
    填写 API 配置后，页面按所选协议逐条或并行请求上游，边生成边显示回复。取样完成后可以自动开始验证。每条样本独立取样：一条取样时，其他样本仍可开始取样、停止、编辑或清空；样本卡的停止只中止该条，操作栏的停止中止全部。
  </Tab>
</Tabs>

## API 配置

| 字段 | 说明 |
| --- | --- |
| 接口地址 | Base URL 或完整端点。以协议端点（如 `/chat/completions`）结尾的地址原样使用，以 `/v1` 结尾的地址补上端点，其他地址会补上 `/v1` 和端点；基础路径不是 `/v1` 的接口请填完整端点 |
| 模型 | 请求中的模型名 |
| API Key | 默认隐藏，可以切换显示 |
| 推理强度 | 可留空，也可以填写上游支持的任意 `reasoning_effort` 值 |
| 接口协议 | Chat Completions、Messages 或 Responses |

配置下方的开关，默认全部开启：

- **流式输出**：使用 SSE 边生成边显示；关闭后等待完整的 JSON 响应。
- **并行请求**：三个样本同时发送，分词器探测每批发 4 个请求；关闭后逐个发送，耗时更长。
- **宽松模式**：流式取样收到要求数量的完整有效整数后就停止；非流式回复超出要求时只取前 N 个。两者在界面上标为“已截断”。关闭后要求上游自然完整结束。
- **取样完成后自动验证**：三条样本都成功、且没有其他样本仍在取样时，自动计算结果。
- **分词器探测**：取样时多发约 12 个短请求（最多 22 个），识别上游使用的分词器并入置信度；按次计费的接口会多计这些请求，见[分词器探测](./tokenizer.mdx)。

配置和密钥自动保存在浏览器的 localStorage 中，刷新或重新打开后恢复。配置菜单支持多份预设：重命名、新建、复制和删除；“保存”只在浏览器中确认当前配置，“导出”和“加载”在文件与浏览器之间转移配置，导出的文件包含 API Key 明文，不要发给别人或上传到网盘。“转发代理”是浏览器级设置，不属于任何一份预设，见[直连与代理授权](./connection.mdx)。

## 阅读结果 [#reading-results]

三条回答都有效时，结果区按排名顺序列出参考库中的候选，每行显示一个置信度：

- 置信度经过校准时，是参考库内的相对概率：全部候选合计 100%，不包含库外模型；
- 未校准时，显示核验分数的估计值，不代表概率。

API 模式下，置信度已并入[分词器探测](./tokenizer.mdx)的结果，第一候选的家族名旁有一个徽标，说明它的分词器与实测是否一致。

第一候选的置信度低于 75% 时，页面提示“置信度不足”。只有一两条回答有效时，只显示排名，不显示置信度。命令行还会在排名第一的候选与核验器首选的候选不同时标注分歧，见[检测](../cli/detect.mdx#results)。

某条样本的最小有效数字不低于 200 时，页面把它标为分布异常，结果不可靠。这种分布由提示词引起，用原提示词重测仍会出现：API 模式下，“更换提示词并重测”为这些样本生成新的挑战，并沿用原取样参数立即重新取样；手动模式下，“更换提示词”只替换提示词并清空对应回复。其余样本保持不变。这一提示不参与评分。

<Callout type="warn" title="排名不是身份证明">
  库外模型也会得到一个“最像”的候选。测得同名结果可以作为支持证据，但不能独立证明身份；测得其他模型也不能直接断定模型被替换，因为某些模型的指纹天然接近。本站无法可靠检验间歇性替换模型的行为。
</Callout>

## 导出

- **PNG 图片**：在浏览器 Canvas 中按两倍像素密度生成，包含站名、日期、第一候选、前五项、有效样本数和限制说明，使用当前语言与主题；不包含 API Key、接口地址、所填模型 ID 或回复正文。
- **JSON**：候选列表与置信度；有分词器结果时，另带每个候选的分词器一致性和每个请求的计数。不含接口地址和 API Key。
- **样本库页面**：按模型浏览参考回复与各自的原始提示词，可以搜索、按家族筛选，并导出为 JSONL；导出前会去掉密钥和授权字段。
