To change the design spec, edit `web/design.md` in the repository. This page shows its contents. The spec is written in Chinese with the project's `ikadesign3` skill (`.agents/skills/ikadesign3/`), and it covers presentation only: features, fields, and thresholds come from the code. `[MUST]` marks a hard requirement. `[SHOULD]` marks the default, and items noted 决策 (decision) give their reason. `[UNCONFIRMED]` marks an inference that nobody has confirmed yet, with its source.
