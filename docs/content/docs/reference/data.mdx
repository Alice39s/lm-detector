`data/` 保存正式参考样本、派生指纹库、冻结检测参数、固定采样挑战和词表探测的指纹库。

```files
data
├── unified_reference.jsonl
├── unified_bank.json
├── shared_detector.json
├── enrollment-suite.json
├── tokenizer_bank.json
├── import_manifest.json
├── archive
└── collections
```

| 文件 | 内容 |
| --- | --- |
| `unified_reference.jsonl` | 参考批次，每行一个版本 1 批次：共用模型、渠道与调用设置，回答放在 `samples` 数组中 |
| `unified_bank.json` | 由参考批次派生的统计库 |
| `shared_detector.json` | 冻结的排名器、核验器和校准参数，用 SHA-256 绑定参考数据 |
| `enrollment-suite.json` | 36 道固定采样挑战；它是采样输入，不是参考回答 |
| `tokenizer_bank.json` | 词表探测用的探针、词表类计数和型号映射 |
| `import_manifest.json` | 历史清单，不代表当前数量 |
| `archive/` | 已退出参考库的历史批次 |
| `collections/` | 采样请求、尝试和来源核验记录 |

`archive/` 与 `collections/` 不参与评分，也不复制到网站的公开数据。批次与样本的字段见[采样与续采](../cli/sampling.mdx#batch-format)。

## 维护规则

- `fpd sample`、`fpd enroll DIR` 和 `fpd retrain --data-dir DIR` 都可以在仓库外运行。入库校验完整批次和原始证据，按模型、渠道、条件、题目与文本去重并重建派生库；重训从目标参考库离线拟合核验器与置信度，嵌套校准未通过时不替换 `shared_detector.json`，训练证据保存在 `.training/`。
- CLI 随包数据只读；维护目标必须显式指定，或在交互入库时识别本仓库后确认。
- 固定评估集不能加入参考库、模型中心或校准。
- 网站构建把脱敏数据写入 `web/public/data/`。该目录是生成产物，不能作为另一份正式库维护。

## 词表库

`tokenizer_bank.json` 由词表归档工具 llm-tokenizer-fingerprint 的 `token-fp export-api-bank` 从 290 个开源词表离线生成。它与参考样本无关，更新时直接整体替换，不经过 `fpd enroll`。

| 字段 | 内容 |
| --- | --- |
| `schema` | 固定为 `tokenizer-bank-v1` |
| `source` | 生成工具、词表数与候选文本数；`archive_manifest_sha256` 记录所用存档清单的哈希，`excluded` 列出因存档文件不可信而未导出的仓库及原因 |
| `wrapper` | 请求包裹：`prefix` 与 `suffix` |
| `probes` | 探针的 ID、类别与原文 |
| `classes` | 每类词表的实验室、系列、成员、别名，以及对每条探针的计数差 `counts`；成员分歧时另列 `alternatives` |
| `api_models` | 第一方型号到词表类的映射；`class` 为 `null` 表示厂商没有公开词表 |

词表类按作者实验室与系列归并：行为完全相同的词表归为一类，同一谱系下只差少数文本的再合并。完整的类列表见[词表探测原理](../principles/tokenizer.mdx#classes)。
