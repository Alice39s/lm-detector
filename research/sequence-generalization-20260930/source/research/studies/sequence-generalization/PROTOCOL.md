# 通用序列指纹研究（2026-09-30）

目标：比较通用频率、序列位置、顺序依赖和分类方法，提高整个参考库的识别，并检查 gpt-6-astra / gpt-6.1-sol 的真实可分性。蒸馏关系由用户提出，本研究只验证输出行为，不把它作为已证实的因果解释。

## 数据和选择规则

- 冻结当前参考 JSONL、bank 和 shared detector 的 SHA-256。现有未提交数据视为输入，保持原样。
- 参考库采用 12 个环境逐一留出。每组稳定选取 query-01..36 中对应的三条回答；同挑战的额外回答必须随环境一起留出。预处理、特征缩放和分类器仅拟合该折训练部分。
- 候选选择以全部模型的三回答 Top-1 为主，同时报告宏平均、Top-3、两者各自命中率。不能仅凭目标模型对的提升选型。
- 交叉验证既用于方法筛选又用于估计时，结果明确标为开发估计。置信度温度只用参考交叉预测拟合；不把闭集概率称为后端身份认证。
- 固定 holdout 仅用于回归验证，不参加训练、预处理、参数选择或校准。它缺少 Sol，所以不能认证两者可分。
- 新配对集预先生成 20 轮，每轮三条共同挑战，两模型使用同一 OpenAI Responses API 参数。它作为新的外部验证集，不加入参考库、训练或校准。所有候选及融合权重冻结后才评分。
- 旧 OpenRouter 配对集作为已探索的跨渠道回归集；不能视作新的独立验证。

## 候选和判断

比较当前 Ensemble、正则化线性分类器、值与归一化位置的相关矩、位置桶分布、滞后统计、转移统计以及频率与序列的融合。避免依据渠道、响应速度、模型元数据或存储格式分类。

报告单回答与三回答准确率；对多组证据的累加只采用固定、不重叠分组，不能把自助法重采样当独立样本。报告 90% / 95% 概率阈值上的覆盖、命中和错误数，以及二项置信区间。没有足够独立验证时不得称为已实现高置信度区分。

## 采集

两者均使用 low、stream=true、store=false、max_output_tokens=8192，保持默认采样参数、不发送工具。检查实际 response.model 等于请求标签或其日期版本，检查完成状态和最少合法数字数量。只按完整性接纳，不按分类结果重采。每个位置最多两次尝试，失败、无效和旧尝试全部保存。密钥只从环境或私有临时文件读取，不能进入 manifest、源码或报告。

采集修订：round-17 的 Sol 第 2 条连续两次 socket 失败，在任何外部评分前将该位置的上限扩展到三次。相同提示词、请求参数和失败记录保持不变，修订记在 manifest.retry_extensions。另修正采集器将 HTTP 200 后的流中断误判为不可重试的条件，使 round-15 的首次超时可以按原计划重试。

只有在全部模型的改进和新外部验证支持时才考虑修改产品评分器；研究成功与产品交付分别报告。
